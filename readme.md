# Proyecto de Automatizacion QA - Diego Cabezas

## Descripcion

Proyecto de automatizacion de pruebas realizado con Python,
Selenium WebDriver y Pytest.

El objetivo del proyecto es automatizar distintas pruebas
funcionales de una aplicacion web.

## Tecnologias usadas

- Python
- Selenium WebDriver
- Pytest
- Pytest html
- Git

## Ejecutar test
pytest -v --html=reporte.html
pytest -v
