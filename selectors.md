#PreEntrega - TalentoTech

##Entregables

###Page Login
- Input Usuario: 
    Usermame: #user-name (id del campo de texto para usuario)
- Input Password:
    Password: #password (id del campo de texto para contraseña)
- Botón de Login:
    Login Button: #login-button (id del botón de submit para nicio de sesión)
- Mensaje de error de Login:
    [data-test="error"] - .error-message-container h3 (mensaje de error de login)


##Inventory Page
- Listado de productos:
    .inventory_item (clase del contenedor de cada producto)
- Nombre del producto:
    .inventory_item_name (clase del título de cada producto)
- Botón agregar al carrito:
    .btn_inventory (clase del botón para agregar producto al carrito)
- Botón de Filtro de productos:
    .product_sort_container (clase del select de ordenamiento)
- Botón de menú:
    #react-burger-menu-btn (id del botón de menú)
- Botón para ingresar al carrito:
    .shopping_cart_link (clase del enlace al carrito)
- Indicador de cantidad de productos en el carrito de un producto:
    .shopping_cart_badge (clase del contador de productos en el carrito)

##Cart Page
- Fila de carrito:
    .cart_item (clase del contenedor del producto en el carrito)
- Nombre del producto en carrito:
    .inventory_item_name (clase del nombre de producto dentro del carrito)
-Botón seguir comprando:
    #continue-shopping (id del botón para seguir comprando)
